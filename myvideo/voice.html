What is Docker — Shipping Container Analogy
0:30 – 1:30
Nepali

Visual
Animate old chaotic ship loading → then a standard container snapping into place perfectly.
Both
Docker exactly त्यही गर्छ — तर software को लागि। Timro application — code, libraries, configs, sab kei — ek container ma pack hudcha. Tyo container jaha pani lagaau — timro laptop ma, AWS ma, Azure ma, colleague ko machine ma — same result. Guaranteed.
English
Think of it this way — a Docker container is a self-contained box. Everything your app needs to run lives inside that box. The environment outside doesn't matter anymore.

SCENE 05
Windows Installation Walkthrough
3:00 – 6:00
Nepali
Aba hands-on। Install garau। Timro PC ma Windows 10 wa 11 chahiyo — Home wa Pro duitai chalcha। Pahile hami WSL2 enable garnu parchha — yo Windows Subsystem for Linux ho — basically Windows bhitra Linux chalnu dine feature.
1
Start menu kholau, "Turn Windows features on or off" search gara। Tyaha Windows Subsystem for Linux ra Virtual Machine Platform — duitai check box lagau। Restart maagna sakcha — lagaideu।
2
Restart paachi PowerShell admin ma kholau ani run gara: wsl --set-default-version 2 — yo command le WSL2 lai default banaunchha। Simple।
3
Ab browser ma jau — docker.com — Get Started click gara — Docker Desktop for Windows download gara। File size around 500MB hunchha, so internet speed anusaar time lagcha।
4
Downloaded installer run gara। Setup wizard ma "Use WSL 2 instead of Hyper-V" — yo checked rahana deu। Default settings chalcha — Install click gara। Complete huna केही minutes lagcha।
5
Docker Desktop open hunchha — whale logo dekhnuchha taskbar ma। Yo ayo matlab Docker running chha। Ab terminal kholau।
6
terminal — PowerShell wa Command Prompt — kholau ani type gara: docker --version। Output ayena bhane restart garera hera। Aayo? Great — installation successful छ।
7
Aba magic moment। Type gara: docker run hello-world

Pahilo palta run garnu bhayo bhane Docker le automatically image pull garcha internet bata। Ani ek message aunchha — "Hello from Docker!" — yo ayo bhane timi officially Docker suru garisakeya! System kaam gariraakhyo।
Nepali
Kasai lai problem aayo? Tala comment section ma lekha — ma reply garchu। Common issue hunchha — Virtualization disabled — tyaso bhaye BIOS ma gae enable garna sakcha, next video ma tyo ni cover garchu।

Full screen recording throughout. Highlight each click. Show terminal output clearly. Zoom into "Hello from Docker!" message at the end.
