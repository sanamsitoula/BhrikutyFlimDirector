How Blockchain Works

Long-form (12 min) and short-form (65s) for Phase 1.

HOOK (0:00–0:12)
"In 2022, a crypto exchange called FTX collapsed in 72 hours. Eight billion dollars in customer funds — gone. No warning. No recourse. No refunds. That same week, the Bitcoin blockchain processed over 200,000 transactions. Zero errors. Zero downtime. Same industry. Completely different result. Today, we are going to understand exactly why."
ON-SCREEN: "FTX: $8B lost in 72 hours" · "Bitcoin network: 0 errors that week"
SECTION 1 — THE TRUST PROBLEM (0:12–2:30)
"Every financial system has the same design flaw. It requires you to trust someone else. [...] Computer scientists called this the Byzantine Generals Problem. [...] Then in 2008, an anonymous developer named Satoshi Nakamoto published a 9-page paper. The solution: a chain of blocks."
ON-SCREEN: Byzantine Generals diagram · "Satoshi Nakamoto · 2008"
SECTIONS 2–5 + CTA

03b — Scripts · Phase 2

Bitcoin vs Ethereum — What's Actually Different

Long-form (14 min) and short-form (65s) for Phase 2.

HOOK (0:00–0:15)
"What if your money had a hard limit? Not a soft limit. Not a government policy. Not a promise. A mathematical guarantee, enforced by code. 21 million. No more. Ever."
ON-SCREEN: "21,000,000 BTC — hard maximum. Forever." [#00D4AA · counter] · "No vote. No exception. No override." [#8B9BB4]
SECTION 1 — WHAT MAKES BITCOIN DIFFERENT (0:15–2:30)
"Digital money is not new. PayPal launched in 1998. [...] So what did Bitcoin actually change? Three things. First: no issuer. [...] Third: a fixed supply. No entity can create more Bitcoin. The total supply is 21 million — written into the code in 2009. [...] Bitcoin's rules are set by math. The code IS the policy."
ON-SCREEN: "NO ISSUER · NO GATEKEEPER · FIXED SUPPLY" [#00D4AA] · "Bitcoin's rules: set by math, not committee" [#8B9BB4]
SECTION 2 — PROOF OF WORK (2:30–5:00) · INFOGRAPHIC: card_01
"Every 10 minutes, miners compete to solve a puzzle. The puzzle: find a number — called a nonce — such that when you combine it with the block's data and hash the result, the output starts with a specific number of zeros. There is no shortcut. There is no formula. [...] This mechanism is called Proof of Work."
SECTION 3 — BITCOIN'S SUPPLY (5:00–7:30) · INFOGRAPHIC: card_02
"2009: 50 BTC per block. 2012: 25 BTC. 2016: 12.5 BTC. 2020: 6.25 BTC. 2024: 3.125 BTC. [...] Total supply: 21 million. Final. As of 2024, about 19.7 million Bitcoin have already been mined. Only 1.3 million remain."
SECTION 4 — ETHEREUM (7:30–9:30) · INFOGRAPHIC: card_03
"In 2013, a 19-year-old named Vitalik Buterin asked a different question. What if we could run code without a server? His insight: a blockchain is not a ledger. It is a shared, unstoppable computer. [...] Bitcoin is a vending machine. Ethereum is a general-purpose computer."
SECTIONS 5–6 + CTA (9:30–14:00)
Section 5: Proof of Stake / The Merge (Sept 15 2022) — 32 ETH staking, slashing, −99.9% energy. Section 6: Private key → public key → address, mailbox analogy. CTA: Phase 3 DeFi tease. Full script in phase_2/script.md
HOOK (0:00–0:04)
"Your crypto is not actually inside your wallet."
TITLE CARD: "YOUR BITCOIN ISN'T IN YOUR WALLET." · "Common misconception: fixed." [#00D4AA]
MAIN (0:04–0:52)
"Your Bitcoin lives on the blockchain. What the wallet holds is the key that proves you own it. There are three layers. ONE: the private key. A 256-bit random number. Whoever holds this owns the coins. Lose it — gone forever. [...] TWO: the public key. Derived from the private key through one-way math. [...] THREE: your address. This is what you share. Like a mailbox number."
ON-SCREEN: "1 · PRIVATE KEY → proves ownership" [#F5A623] · "2 · PUBLIC KEY → one-way derived" [#8B9BB4] · "3 · ADDRESS → your shareable mailbox" [#00D4AA] · "Lose private key → coins gone. Forever." [#7B5CF0]
CTA (0:52–1:05)
"Full 14-minute breakdown: Bitcoin vs Ethereum. Chain Clarity — blockchain, without the noise. Subscribe for Phase 3: DeFi."

03c — Scripts · Phase 3

DeFi & Smart Contracts — How Finance Works Without Banks

Long-form (14 min) and short-form (65s) for Phase 3.

HOOK (0:00–0:15)
"In 2010, getting a bank loan meant paperwork, credit checks, meetings. In 2024, a protocol lent someone $10 million in seconds. No meeting. No signature. No banker. The code processes the loan. Instantly."
ON-SCREEN: "THE CODE PROCESSES THE LOAN." [#00D4AA · 72px]
SECTION 1 — SMART CONTRACTS (0:15–2:30) · INFOGRAPHIC: card_01
"A smart contract is a program that runs on a blockchain. When conditions are met, it executes automatically. No one needs to approve it. No one can stop it. Think of a vending machine. You insert money. The machine checks the amount. If correct, it releases the snack. No human involvement. That's a smart contract. [...] The code is the bank."
ON-SCREEN: IF/THEN flow — "IF: Deposit 150 USD ETH" → "THEN: Release 100 USD loan" → "IF: Collateral < 120 USD" → "THEN: Auto-liquidate" · "THE CODE IS THE BANK." [#00D4AA · 80px]
SECTION 2 — DEFI LENDING (2:30–5:00) · INFOGRAPHIC: card_02
"The two biggest DeFi lending protocols are Aave and Compound. [...] To borrow 100 dollars of USDC, you post 150 dollars of ETH. That's 150% collateralization. [...] Think of it like a pawn shop with no pawnbroker. [...] Automatic. Instant. Unstoppable."
ON-SCREEN: LENDER [#00D4AA] ⇌ POOL ⇌ BORROWER [#F5A623] · "OVERCOLLATERALIZED: 150%+" [#F5A623]
SECTION 3 — AMMs (5:00–7:30) · INFOGRAPHIC: card_03
"There's no order book. Instead: a liquidity pool. Two assets sit in a smart contract. The price is set by a formula: x times y equals k. [...] No one sets the price. The math does. Protocols like Uniswap, Curve, and Balancer use this model."
ON-SCREEN: "x × y = k" [JetBrains Mono · #F5A623 · 72px] · "NO ONE SETS THE PRICE. THE MATH DOES." [#00D4AA]
SECTION 4 — YIELD + RISKS (7:30–9:30)
"Two yield sources: trading fees and protocol incentives. [...] But there's a catch: impermanent loss. [...] In 2020, Harvest Finance lost $34 million in a single transaction. [...] If you don't understand where the yield comes from — walk away."
SECTION 5 — STABLECOINS (9:30–11:30)
"Three types: fiat-backed (USDC/USDT), crypto-backed (DAI), algorithmic. In May 2022, Terra's UST lost its peg. Forty billion dollars in value — destroyed in four days. The mechanism failed. The peg broke."
ON-SCREEN: "$40 BILLION" [#F5A623 · 96px] · "Destroyed in 4 days." [#FFFFFF · 48px]
SECTION 6 — RISKS + CTA (11:30–14:00)
Smart contract risk · Protocol risk · Liquidation risk · Rug pulls ("This is fraud.") · Oracle risk · Regulatory risk. CTA: Phase 4 tease — Security & Self-Custody. Full script in phase_3/script.md

"A smart contract does something no bank can. It cannot lie."
TITLE: "SMART CONTRACT" · "Cannot lie. Cannot delay. Cannot deny." [#00D4AA]
MAIN (0:04–0:52)
"A smart contract is a program that runs on a blockchain. No human controls it. No company owns it. Once deployed, it executes exactly as coded. Three rules: ONE — conditions are in the code. TWO — when met, execution is automatic. THREE — nobody can stop it."
ON-SCREEN: "1 · CONDITIONS IN CODE" [#F5A623] · "2 · EXECUTION IS AUTOMATIC" [#00D4AA] · "3 · NOBODY CAN STOP IT" [#7B5CF0]
